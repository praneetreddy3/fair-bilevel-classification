UCI Adult — local folder UCIAdultdataset
=========================================

Data: adult.data (train, 32561 rows) and adult.test (test, 16281 rows), standard UCI split.
Sensitive attribute: sex (Female=0, Male=1). Label: income >50K.

Files generated:
- draft_results_adult.json — full bilevel AL with rho=0.5, J_outer=3, K_inner=40 (stable on Adult)
- draft_results_adult_simplified.json — inner-only path (--no_full_al), 5 rounds

Baseline (ERM on train): accuracy ~0.846, F1 ~0.654, EO gap ~0.011 (small on this split).

Notes:
- Default flags (rho=1.0, full AL) can collapse the global model on Adult; use milder rho and fewer outer AL steps, or --no_full_al for stability.
- Command used for draft_results_adult.json:
  python -m draft_model.run_draft --data adult --sensitive sex --results_file draft_results_adult.json --rounds 3 --num_clients 3 --rho 0.5 --J_outer 3 --K_inner 40
