SECTION 4: WHAT IS UNCLEAR / NOTES
================================================================================

NOTE 1: Client 2 (Moderate) |B| discrepancy with paper example
  FILE: draft_model/check_draft_examples.py
  DETAIL: Paper Appendix 4.2.4 expects |B|=64 for Client 2 (N=900, pi_plus=0.1333).
          Code produces |B|=60 because ceil(8/0.1333)=ceil(60.0)=60, not 64.
          This is a rounding/formula difference in the paper example, not a code bug.
          All other clients match exactly.
  SEVERITY: Informational — the code follows the stated algorithm correctly.

NOTE 2: Universum gradient is zero for 2D dataset client 0
  FILE: draft_model/bilevel_al.py (INV-4 output)
  DETAIL: ||grad(U_x)|| = 0.0 for all outer steps of client 0 on 2D data.
          Root cause: With only 7 training points per client, the cmin_tilde=2
          floor on synthetic positives makes Delta_s=0, so |U|=0. The U tensor
          is empty. This is correct behavior — the Universum is not needed when
          the synthetic batch is already balanced. The code handles this gracefully.
  SEVERITY: Expected behavior for very small datasets. Not a bug.

NOTE 3: Quota adjustment edge case (theoretical)
  FILES: draft_model/minibatch_design.py lines 61-66 and 124-127
  DETAIL: When the positive floor (cmin or cmin_tilde) pushes the quota total
          above the target size, the excess is subtracted from q_a0y0. If
          q_a0y0 is too small, it's clamped to 0 and the final total may be
          less than the target size. This is unlikely with default parameters
          (Ds_size=32, cmin_tilde=2) but could occur with extreme imbalance
          AND small target sizes.
  SEVERITY: Low risk. Did not trigger in any test. Consider adding a
            redistribution fallback if this ever causes issues with custom params.

NOTE 4: L_out uses zeta_out = 0 (not the global reference zeta)
  FILE: draft_model/bilevel_al.py line 129
  DETAIL: L_out is called with torch.zeros_like(zeta_t) as the reference,
          meaning the outer regularization is ||theta||^2 not ||theta - zeta||^2.
          The losses.py docstring says "Lout(theta) = L(theta; B_{k,t}, 0)",
          suggesting this is intentional (outer loss regularizes toward origin).
  SEVERITY: Informational — appears intentional per paper notation.

NOTE 5: 2D dataset is too small for meaningful FL evaluation
  DETAIL: With 30 total points (24 train, 6 test, 4 val) split across 3 clients,
          each client gets ~7 points. Both baseline and pipeline achieve identical
          performance (acc=0.833, EO_gap=0.0). The dataset is useful for
          verifying the pipeline runs but not for demonstrating fairness gains.
  SEVERITY: Informational — use Adult or larger datasets for actual evaluation.
